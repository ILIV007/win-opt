WIN-OPT

Windows Optimizer Wizard

A simple terminal wizard that raises your Windows health a bit. For people who never maintain their system: it runs real, safe, built-in Windows commands, step by step, shows you each command first, and shows you its result.

01 / How to use

  1. Download the .zip above — it contains the script, the launcher, and win-opt.exe — or grab the standalone .exe instead.
  2. Unzip, then double-click Start-WinOpt.bat — or right-click it and choose Run as administrator. The .exe asks for admin itself.
  3. Pick a mode. The wizard asks only when it needs a decision — temp cleanup, power plan — each step shows its command before it runs.

03 / What Apprentice does

  1. Checks the internet quietly in the background (no questions) and notes the result in the log.
  2. Creates a restore point first. If none can be created, it stops — no repair or cleanup runs without a safety net. (If a restore point from today already exists, it uses that one.) A restore point is not a backup.
  3. Flushes the DNS cache (ipconfig /flushdns).
  4. Cleans old temp files — only after asking you first and showing what will be deleted. Only files older than 7 days, only folder contents, locked files skipped.
  5. Opens Settings so you can turn on Storage Sense and run it yourself.
  6. Optimizes the system drive (Optimize-Volume, media-aware: TRIM on SSDs, defrag on hard drives).
  7. Shows your power plans, records your current one, and offers Balanced or High Performance — your choice, with a laptop battery warning.
  8. Lists your startup apps and opens Task Manager so you can review them yourself. win-opt never turns anything off.

Every run writes a log to %TEMP%\win-opt\.

04 / Safety rules

  • Only safe built-in commands. Anything dangerous gets a warning and needs your explicit yes.
  • No registry edits. No cleanmgr auto-run. No DISM, SFC, or chkdsk in Apprentice. No network reset, no driver or app updates, no disabling of Defender or Windows services.
  • Nothing is deleted blindly: temp cleanup always asks first and shows counts and sizes before deleting.
